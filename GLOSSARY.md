# ML Course — Vocabulary Wall (GLOSSARY)

One canonical glossary for the whole course (session-creation-guide §13). Every session author adds their session's new terms here, with the kid-friendly definition used in that session. Persian term first, English term in parentheses on first introduction in decks.

| Term | Kid-friendly definition (as introduced) | Session |
|---|---|---|
| ویژگی (Feature) | a clue — one column of the data table | S1 |
| برچسب (Label) | the answer — the column we want to predict | S1 |
| نمونه (Example) | one row = one set of clues + its answer | S1 |
| یادگیری نظارت‌شده (Supervised learning) | studying solved examples (with the answer key), then facing the exam with answers hidden | S1 |
| مدل (Model) | the student that studies the examples — built with `fit`, questioned with `predict` | S1 |
| گره (Node) | a question in the tree — a fork with a signpost | S2 |
| شاخه (Branch) | one answer's door (yes/no) out of a node | S2 |
| برگ (Leaf) | the final room — where the game ends and the verdict is said | S2 |
| ریشه (Root) | the first question — the fork every animal meets first | S2 |
| عمق (Depth / max_depth) | the longest question path — how many questions the machine may ask at most | S2 |
| خلوص (Purity) | how sorted a box is — how close it is to ONE thing per room | S3 |
| آنتروپی (Entropy) | the surprise level of a box — 0 when pure, bigger as the mix grows | S3 |
| بهرهٔ اطلاعاتی (Information gain) | the surprise a question removes — before minus after; the machine's score for every question | S3 |
